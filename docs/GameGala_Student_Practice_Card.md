# GameGala 2026 Student Practice Card

## Intro
"Hi, my name is [Name], and my project is called Flight Carbon Tracker. I designed it because people can see the price of a flight, but they usually cannot see the carbon impact. I wanted to turn an invisible problem into something people can actually see."

## Demo Order
1. `Home`
   "This is my dashboard. It shows my total flight carbon, recent flights, and quick stats."
2. `Add Flight`
   "Here I can look up a flight, estimate the carbon, and save it."
3. `Compare`
   "This helps users understand what the carbon number means in real life."
4. `Reports`
   "This shows patterns over time, like this month and this year."

## Simple Tech Line
"I built the app in Flutter, I save data with Firebase, and I use Google’s Travel Impact Model to estimate emissions."

## Best Creator Phrases
- "I designed..."
- "I decided..."
- "I wanted..."
- "I built this to help people..."

## Judge Answers
`How did you build this?`
"I built it in Flutter, used Firebase to save data, and used Google’s Travel Impact Model to estimate flight emissions."

`What was the hardest part?`
"The hardest part was making the flight data, carbon numbers, and saved results all work together correctly."

`Why did you choose this idea?`
"I chose this idea because people usually do not see the environmental cost of flying."

`What would you improve?`
"I would add goals, more route choices, and more ways to help users lower their footprint."

`Did you use AI?`
Choose the true one:
- "Yes, I used AI as a helper for ideas or debugging, but I made the decisions, tested it, and built the project myself."

## If Something Breaks
- "I can explain what normally happens here."

## Standout Lines

- "I designed this so one travel choice can become a smarter environmental choice."

## Closing
"I’m proud of this project because it connects coding with a real-world problem and helps people make smarter travel choices. Thank you."

## Before You Start
- Slow down
- Breathe
- Smile
- Speak clearly
- One step at a time
